KdM-Manager is a local media download manager (Python + FastAPI + Uvicorn) that uses aria2c for maximum-speed multi-threaded downloads and yt-dlp + ffmpeg for video/audio extraction and merging.

Features include a smart queue (max 3 concurrent), batch URLs, playlist support, auto-categorization into Videos / Audio / Images / Documents / Archives, duplicate handling, a stats dashboard, tags, themes, and a Manifest V3 browser extension that intercepts downloads and adds a right-click "Download with KdM-Manager" option.
